## 背景与问题

用户需要在本机完成日常记账与家庭净资产查看，不依赖假银行连接。参考鲨鱼/钱迹的记一笔效率、Copilot/Monarch 的账户走势、挖财式手动持仓，在 Klarna 粉白视觉下做成四项可切换、可持久化的原型。

## 目标与成功标准

- 用户能在四 Tab 内完成记流水、看预算、管账户与持仓、导出备份。
- 净资产包含 **账户余额 + 手动维护的股票/ETF/基金市值**。
- 刷新或关闭浏览器后数据仍在（`localStorage`）。
- 页面上每一项可点击、可改、可存；无「已连接银行」等不可操作展示。

## 用户、角色与场景

- **个人记账者**：记收支、看本月预算与日均可花、核对流水。
- **家庭账**：流水可标「家庭」，筛选范围「只看我的 / 家庭」。
- **手动投资者**：在账户 Tab 维护持仓（无证券子账户），与银行卡余额分开。

## 范围

### 本次包含

- 四 Tab：**总览、流水、账户、我的**（hash 兼容 `today/book/assets/me`）。
- 本机账本：`accounts`、`entries`、`holdings`、`templates`、预算与分类、资料与设置。
- 总览：净资产、本月收支结余、月预算与分类预算进度、日均可花、超支节奏提示、支出曲线、固定扣款识别、待核对入口。
- 流水：列表/日历、搜索与筛选、分类饼图与支出排行（较上月升降）、FAB 记一笔。
- 账户：净资产 hero 与走势（7D/1M/3M）、账户分组与详情、转账（双分录）、**股票/基金持仓分组**（手动）。
- 我的：连续记账、设置（预算、导入/导出 JSON、隐私、语言、货币）、快捷模板、分类管理。

### 不在本次范围

- 银行/券商 OAuth、假同步、预置真实持仓、自动 OCR/语音记账。
- 证券子账户、买卖成交回放、历史价曲线、行情自动刷新（可后续版本）。
- 多账本、报销、周期账提醒、iOS/Android 安装包。

## 用户故事

1. 作为记账用户，我希望快速记一笔收支，以便本月支出与预算实时更新。
2. 作为用户，我希望看到净资产含持仓，以便不必在记账 App 外心算。
3. 作为用户，我希望导出/导入 JSON，以便换设备或备份。
4. 作为用户，我希望维护股票/基金份额与现价，以便浮动盈亏正确显示。

## 能力与信息架构

```text
总览 ─ 净资产(含持仓)、预算/还可花、曲线、待核对、固定扣款
流水 ─ 列表|日历、筛选、饼图、排行、记一笔(FAB)
账户 ─ 走势 hero、银行/现金/卡/其他、股票组|基金组、转账、添加账户|添加持仓
我的 ─ 资料、设置卡、模板、分类
```

子页（面板）：记一笔、筛选（范围/时间）、预算、转账、账户编辑/详情、持仓编辑/详情、资料、隐私。

### 功能清单（与实现对齐）

| 模块 | 能力 |
| --- | --- |
| **总览** | 净资产 hero（含持仓）；本月支出/收入/结余；月预算进度、剩余、**日均可花**、超支节奏文案；支出曲线（点日跳流水）；待核对队列与**全部标为已核对**；**固定扣款**（120 天内同标题同金额支出≥2 次，点开编辑样例）；**本月分类**横向 chip（含分类预算进度条，点进流水并筛分类）；顶栏 **范围** chip → 筛选页 |
| **流水** | 顶栏 **时间** chip → 筛选页；搜索；列表/日历；核对状态筛选；分类/账户筛选 chip；周期饼图 + **支出排行**（较上月升降）；FAB/记一笔；点分类饼图 toggle 筛选 |
| **账户** | 走势 hero（7D/1M/3M、区间变动）；有持仓时 hero 副行展示 **账户余额 + 持仓市值**；账户分组与行内区间 **涨跌 %**；详情（余额、区间变动、区间净流入、单账户曲线、编辑、**查看流水**带账户筛）；转账；添加账户 / **添加持仓**（股票组含 **ETF**，基金组含 fund） |
| **我的** | 资料（昵称、性别）；连续记账天数；设置卡（月预算入口、导出/导入、隐私、语言、货币）；快捷模板（应用/删除、**不可重复保存**）；分类增删（编辑模式） |
| **记一笔** | 收支；常用备注 chip；分类按 **使用频次** 排序；无账户时可填账户名并 **自动建现金账户**；家庭标记；保存 / 改删；**保存为模板**（重复模板提示并禁用） |
| **预算页** | 月预算；各分类上限（占位 hint，留空不设）；保存；可 **清空预算** |
| **数据** | 示例账（可一键清空）；`localStorage` 持久化；导入失败不覆盖 |

## 数据模型

存储键：`ledger-book-v1`（浏览器 `localStorage`）。

| 对象 | 说明 | 关键字段 |
| --- | --- | --- |
| **Book** | 整本账 | `nickname`，`gender`，`locale` zh/en，`currency` USD/EUR/CNY（仅影响符号，不换算），`monthlyBudget`，`categoryBudgets`，`categories`，`sampleCleared` |
| **Account** | 现金类账户 | `id`，`name`，`opening`，`kind`：bank/cash/card/other |
| **Entry** | 收支流水 | `title`，`amount`，`direction` in/out，`category`，`date`，`accountId`，`shared`，`checked` |
| **Holding** | 持仓（无证券户） | `kind` stock/etf/fund，`code`，`name`，`qty`，`costTotal`（总额），`price`，`priceAsOf` |
| **EntryTemplate** | 快捷模板 | 同记一笔字段子集，绑 `accountId` |

**净资产**：`Σ 账户余额(entry 联动 opening)` + `Σ (qty × price)`。

**浮动盈亏**：`市值 − costTotal`；录入时用户填 **成本价（每股/每份）**，保存为 `costTotal = qty × 成本价`。

**模板**：相同模板（备注/金额/方向/分类/账户/家庭）不可重复保存。

**持仓**：相同 `kind + code` 不可重复添加（保存时静默拒绝）。

**示例账**：无账户且无流水时可注入 sample；清空后 `sampleCleared`，不再自动补回。

导入/导出：整本 `Book` JSON，下载名 `ledger-<日期>.json`；`holdings` 随书导入（`parseHoldings` + 成本 legacy 修正）；`templates` 导入去重。

## 业务规则

| 规则 | 条件 | 结果 |
| --- | --- | --- |
| 记一笔 | 金额>0，有标题与分类 | 写入 `entries`；无 `accountId` 时按账户名 **新建 cash 账户** |
| 范围统计 | 总览/流水统计 | **我的**：`shared=false`；**家庭**：仅 `shared=true` |
| 筛选页 | 总览入口 | 改 **我的/家庭**；流水入口改 **今日/本月/自定义** 起止 |
| 转账 | ≥2 账户，金额>0 | 两笔流水，分类「转账」 |
| 月预算 | 正数或清空 | 总览展示剩余/日均可花；分类预算可选上限 |
| 待核对 | `checked=false` | 总览队列；可单笔或全部标已核对 |
| 示例账 | 未清空 | 可一键清空，不再自动补回 |
| 走势含持仓 | V0 | 各日净资产 = 该日账户余额 + **当前**持仓市值（无历史价） |
| 成本迁移 | 旧数据误将每股存进 costTotal | 加载时按启发式修正为总额 |

## 权限与作用范围

- 单机本地数据，无账号体系。
- **家庭**：`shared=true` 的流水仅在范围「家庭」下与总览/流水统计中纳入（与「我的」范围切换一致）。

## 状态、异常与边界

- 无账户：可提示添加账户；有持仓无账户时仍展示净资产 hero。
- 空持仓组：展示说明文案，引导「添加持仓」。
- 导入失败：提示无效文件，不覆盖账本。
- 语言切换：界面即时切换，刷新保持。

## 字段、内容与交互要求

- 视觉：`src/themes/klarna-mobile/DESIGN.md`；净资产 hero 使用 `#0B051D`，金额在深色面上统一为白/半透明白（符号与数字同色）。
- 表单互斥选项（账户类型、收支、标的类型等）：**单行** `ledger-choice-row`，选中近黑底，不用粉底分段块。
- 账户类型：银行卡、现金、信用卡、其他——单行四钮。
- 持仓：标的类型 stock/ETF/基金；代码、名称、份额、成本价、现价、现价日期。
- 下拉账户：`select` 自定义箭头，左右 padding 对称。
- 流水 **列表/日历**、深色 hero **7D/1M/3M** 仍用 `ledger-segment`（非表单 choice-row）。

## 非功能要求

- 国际化：中文/英文文案见 `i18n.ts`。
- 持久化：依赖 `localStorage`；用户清除站点数据会丢失账本（隐私页说明）。

## 风险与依赖

- 持仓走势无历史价，区间涨跌主要反映账户现金变化 + 现价一次性计入。
- 无后端，无法跨设备同步除 JSON 文件外。
