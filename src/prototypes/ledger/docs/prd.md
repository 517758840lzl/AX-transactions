## 背景与问题

用户需要在本机完成日常记账与家庭净资产查看，不依赖假银行连接。参考鲨鱼/钱迹的记一笔效率、Copilot/Monarch 的账户走势，在 Klarna 粉白视觉下做成四项可切换、可持久化的原型。

## 目标与成功标准

- 用户能在四 Tab 内完成记流水、看预算、管账户、导出备份。
- 净资产包含 **账户余额 + 手动维护的股票/ETF/基金市值**。
- 刷新或关闭浏览器后数据仍在（`localStorage`）。
- 页面上每一项可点击、可改、可存；无「已连接银行」等不可操作展示。

## 用户、角色与场景

- **个人记账者**：记收支、看本月预算与日均可花、核对流水。
- **家庭账**：流水可标「家庭」，筛选范围「只看我的 / 家庭」。

## 范围

### 本次包含

- 四 Tab：**总览、流水、账户、我的**（hash 兼容 `today/book/assets/me`）。进入子页时底栏隐藏，返回后出现。
- 本机账本：`accounts`、`entries`、预算与分类、资料与设置。
- 总览：月账单和年账单（支出 / 收入 / 其他）、近月对比、分类构成、备注排行前 10。点进去进入对应流水。待报销、待核对、固定扣款仍在下面。预算在「我的」。净资产在账户页。
- 流水：列表/日历、搜索与筛选、分类饼图与支出排行（较上月升降）、FAB 记一笔。
- 账户：区间净资产卡片（7天/1月/3月/1年/全部）与主题粉折线页、账户分组与详情、归档、信用卡出账日/本期账单、转账（双分录）。填了出账日的信用卡，出账日早上 9:00 本机通知刚结掉的那一期；另填了还款日且不是同一天，还款日早上 9:00 再通知该还的那一期。点通知打开这张卡。
- 记一笔：金额直接填写。可拆成两笔、支出可计入存钱目标、已有支出可退款。删除进回收站，7 天后清除。
- 我的：连续记账、设置（预算、导入/导出 JSON、隐私、语言、货币）、分类管理。

### 不在本次范围

- 银行/券商 OAuth、假同步、自动 OCR/语音记账。
- 股票、ETF、基金持仓，以及行情、买卖回放。
- 多账本、周期账提醒、iOS/Android 安装包。账单提醒只做出账日和还款日，不做预算超支通知。

## 用户故事

1. 作为记账用户，我希望快速记一笔收支，以便本月支出与预算实时更新。
2. 作为用户，我希望看到按账户余额算出的净资产。
3. 作为用户，我希望导出/导入 JSON，以便换设备或备份。

## 能力与信息架构

```text
总览 ─ 月账单/年账单、对比柱、构成、排行前 10、待报销、待核对、固定扣款
流水 ─ 列表|日历、筛选、饼图、排行、记一笔(FAB)
账户 ─ 区间净资产卡片、折线页、银行/现金/卡/其他、转账、添加账户
我的 ─ 资料、设置卡、分类
```

子页（面板）：记一笔、年报、存钱目标、净资产折线、筛选（范围/时间）、预算、转账、账户编辑/详情、资料、隐私。

### 功能清单（与实现对齐）

| 模块 | 能力 |
| --- | --- |
| **总览** | 月账单 / 年账单。支出、收入、其他（只计转出）可切换；显示笔数和合计。月视图用近 6 个月的柱对比，年视图用 12 个月。点一根柱切到那个月。下面是分类构成和备注排行前 10，点一行进入对应流水。待报销、待核对、固定扣款仍在这页下面。预算在「我的」。净资产在账户页 |
| **流水** | 顶栏 **时间** chip → 筛选页；搜索；列表/日历；核对状态筛选；分类/账户筛选 chip；周期饼图 + **支出排行**（较上月升降）；FAB/记一笔；点分类饼图 toggle 筛选 |
| **账户** | 白卡片净资产与区间净增长（7天/1月/3月/1年/全部，涨跌用主题粉），点上半部分进折线页（平滑曲线、末点、框、无铺色）；本月进出列出支出、收入、净流入，以及每个有变动的账户，点进去是当月流水；账户分组与行内区间 **涨跌 %** 跟随所选区间；详情是深色余额卡（类型、余额、7天/1月、曲线、区间变动），下面三列支出/收入/净流入可点进流水，信用卡有本期账单，填了出账日则出账日早上 9:00 本机提醒，另填了不同的还款日再提醒一次，再是编辑和**查看流水**；转账；添加账户 |
| **我的** | 资料（头像随所选性别变化，昵称、性别）；连续记账天数；账本（年报、月预算、存钱目标、分类）；显示（隐藏金额就地切换，语言、货币进入下一页）；数据（导出、导入、**清除数据在最后**，这三行都有箭头）；隐私协议单独一行 |
| **记一笔** | 收支；常用备注 chip；分类按 **使用频次** 排序；无账户时可填账户名并 **自动建现金账户**；家庭标记；支出可标 **待报销**；保存 / 改删 |
| **年报** | 支出/收入切换。合计和笔数进入该年流水，结余写在合计旁。分类环和占比，展开后是该分类的备注，再点进对应流水。12 个月对比，标出最多的月份和月均；未到的月份不可点，点已过的月份进入该月流水。大额明细点开那一笔，有退款会标出已退金额。按账户汇总后进入该账户的当年流水。转账不计入。统计跟随「我的/家庭」。上一年/下一年不超过今年 |
| **存钱目标** | 名称、目标金额、已存金额可手填；进度 = 手填已存 + 挂到该目标的支出（上限 100%）。也可从账户存入；可改可删 |
| **预算页** | 月预算；各分类上限（占位 hint，留空不设）；保存；可 **清空预算** |
| **数据** | 示例账（可一键清空）；`localStorage` 持久化；导入失败不覆盖 |

## 数据模型

存储键：`ledger-book-v1`（浏览器 `localStorage`）。

| 对象 | 说明 | 关键字段 |
| --- | --- | --- |
| **Book** | 整本账 | `nickname`，`gender`，`locale` zh/en，`currency` 默认 USD；可选 USD/EUR/JPY/GBP/HKD/TWD/SGD/AUD/KRW/CAD（仅影响符号，不换算；无人民币符号），`monthlyBudget`，`categoryBudgets`，`categories`，`goals`，`sampleCleared` |
| **Account** | 现金类账户 | `id`，`name`，`opening`，`kind`：bank/cash/card/other |
| **Entry** | 收支流水 | `title`，`amount`，`direction` in/out，`category`，`date`，`accountId`，`shared`，`checked`，`claim` none/waiting/done（缺省 none） |
| **SavingGoal** | 存钱目标 | `id`，`title`，`target`，`saved` |

**净资产**：计入资产的账户余额。

**示例账**：新账本默认英语。第一次打开给 3 笔流水（Lunch、Coffee、Metro）和 Cash、Visa 两个账户，分类也是英语。总览、流水、账户上的「清空」和「我的」里的「清除数据」一样，清掉整本账并记 `sampleCleared`，不再自动补回。已经写过自己的流水时，不会被换成这 3 笔。在「语言」里选过的语言会写进账本，下次打开还是这一项，不会改回英语。

导入/导出：整本 `Book` JSON，下载名 `ledger-<日期>.json`。旧账里的 `holdings` 读入时忽略，新导出不再写入。旧版 `templates` 字段导入时静默保留、界面不再展示。

## 业务规则

| 规则 | 条件 | 结果 |
| --- | --- | --- |
| 记一笔 | 金额>0，有标题与分类 | 写入 `entries`；金额只保留数字和一个小数点。无 `accountId` 时按账户名 **新建 cash 账户**。还没有自己添加的账户时，账户下面可点「去添加」，这一路进来不预选现金，要自己点一个类型；保存后回到这笔并选中新账户 |
| 范围统计 | 总览/流水统计 | **我的**：`shared=false`；**家庭**：仅 `shared=true` |
| 筛选页 | 总览入口 | 改 **我的/家庭**；流水入口改 **今日/本月/自定义** 起止 |
| 转账 | ≥2 账户，金额>0 | 两笔流水记在两边账户上，净资产不变。不计入本月支出、本月收入、分类、年报和支出曲线 |
| 账单提醒 | 信用卡填了出账日且未归档 | 出账日当天 9:00 通知刚结掉的那一期（出账日前一天为止）。还款日另填且与出账日不是同一天时，还款日 9:00 再通知该还的那一期。点通知打开该卡。归档、删除或清掉出账日后不再响。隐藏金额时通知里写 ***。第一次有这类卡才询问系统通知权限 |
| 月预算 | 正数或清空 | 总览展示剩余/日均可花。已退款的支出不再占预算；本月支出和收入仍按实际进出 |
| 待核对 | `checked=false` | 总览队列；可单笔或全部标已核对 |
| 待报销 | 支出且 `claim=waiting` | 总览列出；点「报销到账」改为 done，并记一笔同额收入（标题「{名称} 报销」，当天、同账户、已核对）。不重复入账 |
| 年报 | 当前范围、非转账 | 看支出或收入。点合计、分类、备注、月份或账户时，流水按该年或该月，并带上分类、备注、账户。点大额明细打开那一笔 |
| 存钱目标 | 目标金额 > 0 | 已存可以手填。进度 = 手填已存 + 挂到该目标的支出。从账户存入或记一笔挂上目标也会增加 |
| 删除账户 | 编辑账户里删除 | 该账户的流水和转账的另一边进入回收站，净资产不会留下单边 |
| 示例账 | 未清空 | 可一键清空，不再自动补回 |
| 走势 | 各日 | 净资产 = 该日计入资产的账户余额 |

## 权限与作用范围

- 单机本地数据，无账号体系。
- **家庭**：`shared=true` 的流水仅在范围「家庭」下与总览/流水统计中纳入（与「我的」范围切换一致）。

## 状态、异常与边界

- 无账户：提示添加账户。
- 导入失败：提示无效文件，不覆盖账本。
- 语言切换：界面即时切换，刷新保持。

## 字段、内容与交互要求

- 打开后先播约 2.2 秒启动页，再淡入账本。标志是浅粉底上翻开的账本，右页一条上升曲线。名称 SpendLogBook，副文案随语言，下面有转圈。
- 切换后才展开或收起的一块（收支下的待报销和存钱目标、拆成两笔、信用卡账单日、筛选里的自定义日期、流水日历）用约 0.28 秒撑开高度并淡入淡出。打开页面时已经在的内容不播这段。流水页的列表/日历两个按钮切换时不播动画。
- 视觉：`src/themes/klarna-mobile/DESIGN.md`；净资产 hero 使用 `#0B051D`，金额在深色面上统一为白/半透明白（符号与数字同色）。
- 表单互斥选项（账户类型、收支等）：**单行** `ledger-choice-row`，选中浅粉底、深色字。流水日历和日期选择里选中的一天是浅粉底、深色字，有支出的日期底下有浅粉点。
- 账户类型：银行卡、现金、信用卡、其他——单行四钮。
- 下拉账户：`select` 自定义箭头，左右 padding 对称。
- 流水 **列表/日历**、深色 hero **7D/1M/3M** 仍用 `ledger-segment`（非表单 choice-row）。

## 非功能要求

- 国际化：中文/英文文案见 `i18n.ts`。
- 持久化：依赖 `localStorage`；用户清除站点数据会丢失账本（隐私页说明）。
