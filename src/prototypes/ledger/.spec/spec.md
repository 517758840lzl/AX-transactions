# 记账 · 原型主规格

> **同步要求**：与 PRD [`../docs/prd.md`](../docs/prd.md)（权威）及实现保持一致；`src/resources/prd/ledger.md` 为 Make 镜像。变更原型行为时须同时更新 PRD 与本文件。

## 产品定位

本机持久化记账（`localStorage`），信息架构：**总览 → 流水 → 账户 → 我的**（Klarna 粉白视觉）。产品参照见 [app-landscape.md](./references/app-landscape.md)。无假银行/自动同步，每项可操作。完整范围与验收见 PRD。

## 导航（四 Tab）

| Tab | 参考 | 作用 |
| --- | --- | --- |
| 总览 | PocketGuard + 鲨鱼 + 一木 | 月账单/年账单：支出、收入、其他（转账）；合计；近月对比柱；分类构成；备注排行前 10。点合计、柱、分类或排行进入对应流水。下面仍有待报销、待核对、固定扣款。预算在「我的」。净资产在账户页 |
| 流水 | 鲨鱼 + 钱迹 | 列表/收支日历、搜索筛选、饼图 + 支出排行、FAB 记一笔 |
| 账户 | Copilot | 白卡片区间净资产（7天/1月/3月/1年/全部），点进主题粉折线；本月进出（支出、收入、净流入，以及每个账户的进出，点进当月流水）；分组账户、区间涨跌；转账；添加账户 |
| 我的 | 钱迹/随手记 | 连续记账；预算/导入导出/隐私/语言/货币；分类。年报：支出/收入切换，合计进该年流水；分类环可展开到备注；月对比标出最多的月份和月均，未到的月份不可点；大额明细打开那一笔；按账户汇总。转账不计入 |

旧 hash：`today`→总览，`book`→流水，`assets`→账户。进入记一笔或其他子页时，底部四栏隐藏，返回后才出现。

## 数据

- 存储键 `ledger-book-v1`，逻辑见 `store.ts`
- `Book`：`locale`、`currency`（默认 USD；USD/EUR/JPY/GBP/HKD/TWD/SGD/AUD/KRW/CAD，仅符号；无人民币 ¥）、`monthlyBudget`、`categoryBudgets`、`categories`、`accounts`、`entries`、`goals`、`sampleCleared`
- **SavingGoal**：`title`、`target`、`saved`
- **Entry.claim**：`none` | `waiting` | `done`，旧数据缺省 `none`
- 净资产 = 计入资产的账户余额；走势按各日账户余额
- 文案 `i18n.ts`；新账本默认英语。在「语言」里选过的语言会保存，下次打开还是这一项。示例账只有 Lunch、Coffee、Metro，账户是 Cash 和 Visa。总览、流水、账户上的「清空」和「我的」里的「清除数据」一样，清掉整本账后不再补回

## 筛选

- **筛选子页**：总览顶栏改 **我的/家庭**（我的=`!shared`，家庭=仅 `shared`）；流水顶栏改 **今日/本月/自定义**
- 流水：搜索、列表/日历、核对状态、分类/账户 chip；饼图点选分类

## 子页与要点

记一笔（支出可标待报销、退款后退出预算、拆成两笔、计入存钱目标、金额只收数字和一个小数点）、年报、存钱目标（已存可手填，再加上挂上的支出和从账户存入）、预算（含清空）、转账（不进本月收支、分类和年报）、删除账户时流水和转账另一边进回收站、账户归档与信用卡账单、资料（头像随当前所选性别变化，再填昵称）、隐私、筛选、净资产折线、回收站。信用卡填了出账日才有本机账单提醒：出账日早上 9:00 通知刚结掉的那一期；还款日另填且不是同一天才再通知。点通知打开该卡。没填出账日、归档或删除后不响。隐藏金额时通知金额为 ***。第一次出现这类卡才询问通知权限。网页预览没有这条系统通知。无账户记一笔可 **自动建 cash 账户**。还没有自己添加的账户时，记一笔的账户下面可点去添加。从这里进入添加账户时不预选现金，要自己点一个类型，保存后回到这笔并选中新账户。总览：年报入口、存钱目标、待报销到账、固定扣款识别、本月分类 chip（可带分类预算条）、待核对批量标记。账户页是区间净资产卡片，点上半部分进入折线页；账户详情是深色余额卡，下面三列收支可点进流水。总览仍是深色本月卡片。完整清单见 PRD「功能清单」。

## UI 约定

- 打开后先播约 2.2 秒启动页，再淡入账本。标志是浅粉底上翻开的账本，右页一条上升曲线。下面是名称 SpendLogBook、三拍短句（从容入账 · 本机私密 · 账目清楚）和转圈。
- 切换后才展开或收起的一块（收支下的待报销和存钱目标、拆成两笔、信用卡账单日、筛选里的自定义日期、流水日历）用约 0.28 秒撑开高度并淡入淡出。打开页面时已经在的内容不播这段。流水页的列表/日历两个按钮切换时不播动画。
- 主题 `src/themes/klarna-mobile/DESIGN.md`；hero `#0B051D`，深色面金额符号与数字同色
- 表单互斥项：`ledger-choice-row` 单行，选中浅粉底、深色字（账户类型、收支、性别等）。流水日历和日期选择里选中的一天是浅粉底、深色字，有支出的日期底下有浅粉点。语言、货币在「我的」里进入勾选列表。数据里的导出、导入、清除数据都带箭头。
