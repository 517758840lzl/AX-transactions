# 记账 · 原型主规格

## 产品定位

本机持久化记账（`localStorage`），信息架构：**总览 → 流水 → 账户 → 我的**（Klarna 粉白视觉）。产品参照见 [app-landscape.md](./references/app-landscape.md)（含 YNAB、PocketGuard、Bluecoins、Honeydue、薄荷/小星/飞鸭等）。无假银行/自动同步，每项可操作。

## 导航（四 Tab）

| Tab | 参考 | 作用 |
| --- | --- | --- |
| 总览 | PocketGuard + 鲨鱼 + 一木 | 净资产与收支/结余、月预算 + **日均可花** + 超支节奏提示、**分类预算**进度、**固定扣款**提示、支出曲线、待核对 |
| 流水 | 鲨鱼图表 + 钱迹日历 | 列表/**收支日历**切换、搜索与筛选、饼图 + **支出排行**（较上月升降）、按日列表；FAB 记一笔 |
| 账户 | Copilot + Bluecoins | 净资产走势、分组账户、区间涨跌；**账户转账**（双分录）；详情进流水 |
| 我的 | 钱迹/挖财 + 随手记模板 | 连续记账；设置（预算含**分类上限**、导入/导出 JSON、隐私、语言、货币）；**快捷模板**；分类 |

旧 hash：`today`→总览，`book`→流水，`assets`→账户。

## 数据

- 存储键 `ledger-book-v1`，逻辑见 `store.ts`
- 字段 `locale`、`monthlyBudget`、`categoryBudgets`、`templates`（快捷模板）
- 记一笔：**常用备注**、按使用频次排序的分类（鲨鱼式快捷）
- 界面文案见 `i18n.ts`
- 示例账可清空；无账户时可记一笔并自动建账户

## 筛选

- 范围：我的 / 家庭
- 时间：今日 / 本月 / 自定义起止
- 流水页：搜索名称、分类、账户；分类饼图点选筛选
