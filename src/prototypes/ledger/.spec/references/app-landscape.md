# 记账 / 预算 App 参照 landscape

> 用于 ledger 原型取势，不追求功能平铺；**无银行同步的能力只做手动等价物**。

## 海外

| 产品 | 核心主张 | 值得借的 IA / 交互 | 我们原型对应 |
| --- | --- | --- | --- |
| **YNAB** | 零基预算，每块钱有用途 | 分类预算、目标、债务规划 | 月预算 + 分类预算 |
| **Monarch** | 家庭净资产中枢 | 账户分组、净资产曲线、可定制首页 | 账户 Tab 走势 + 分组 |
| **Copilot** | 深色数据优先 | 账户 Tab 净资产图、按类型分组、区间涨跌 | 账户 hero + 分组 |
| **PocketGuard** | 「还可花」一口数 | Safe-to-spend、消费节奏预测、订阅识别 | 日均可花、固定扣款提示 |
| **Honeydue** | 情侣共享 | 部分可见、分类上限、账单提醒 | 「家庭」范围 + 分类预算 |
| **Buddy** | 轻量共享预算 | 自定义分类、伴侣同步 | 家庭账 + 分类 |
| **Bluecoins** | 极客全能 | 转账、标签、日历点日补账、预算 vs 实际表 | 转账、收支日历 |
| **Wallet (BudgetBakers)** | 多钱包 | 钱包列表、周期总览 | 账户分组 |
| **Spendee** | 多钱包总览 | All Wallets、多币种 | 账户合计（非重复流水） |
| **Mint**（已停） | 自动同步聚合 | 分类、预算、信用 — 由 PocketGuard 等承接 | 不做假同步 |

## 国内

| 产品 | 核心主张 | 值得借的 IA / 交互 | 我们原型对应 |
| --- | --- | --- | --- |
| **鲨鱼记账** | 3 秒记一笔 | 明细月汇总、图表排行、月预算、日历 | 预算、排行、日历视图 |
| **钱迹** | 全平台、轻量 | 日历、导出、模板、周期账 | 导出/导入、模板 |
| **一木记账** | 功能全 | 自动记账、订阅追踪、期间预算 | 固定扣款识别 |
| **随手记 / 挖财** | 老牌全能 | 转账、借贷、报销、多账本 | 转账（先做） |
| **薄荷记账** | 免费够用 | 分类预算、智能预选 | 常用备注 + 分类频次 |

| **飞鸭 AI** | 聊天/自动记账 | 多账本、日预算、资产分账户 | 日预算、分账户类型 |

##  deliberately 不做（除非接真能力）

- 银行 / 微信支付宝 **假连接**、OCR 假识别
- 语音 / AI 聊天记账（无后端时做假解析）
- 社区、理财课、算命、开屏广告

## ledger 差异化（四 Tab 内）

- **总览**：净资产 + **预算/还可花** + 支出节奏 + 待核对 + 固定扣款提示
- **流水**：列表/日历 + 排行 + 搜索筛选（鲨鱼图表 + 钱迹日历）
- **账户**：Copilot 式走势 + 分组（不是流水复读）
- **我的**：设置 + **模板** + 导入导出 + 分类/分类预算
